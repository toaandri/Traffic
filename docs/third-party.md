# Composants tiers

Traffic utilise Godot 4.7.2 (MIT), Eclipse SUMO 1.28.0 (EPL-2.0 et licences
secondaires indiquées par la distribution), Python 3.14.2 et les dépendances
répertoriées dans `requirements.lock.txt`. Le lanceur est assemblé avec PyInstaller.

Les notices SUMO distribuées avec les paquets et les textes de licence exportés
par Godot sont conservés dans `docs/licenses`. Les métadonnées de licence des
paquets Python doivent accompagner la version portable. La police Segoe UI est
chargée depuis Windows et n’est pas redistribuée avec Traffic.

Sources des moteurs non modifiés :
- https://github.com/godotengine/godot
- https://github.com/eclipse-sumo/sumo
- https://www.python.org/downloads/source/
- https://github.com/pyinstaller/pyinstaller

Ce fichier documente les composants distribués ; il ne définit pas de licence
pour le code original du projet Traffic.
